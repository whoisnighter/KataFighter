# Material Icon Theme icons

File and folder icons from [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme),
release **v5.40.0**, `icons/` folder, copied unchanged. MIT License, see [LICENSE](LICENSE).

| File | Used for |
|---|---|
| `settings.svg` | `.def` (character definition) |
| `console.svg` | CNS, ST, CMD, ZSS, `.const` |
| `image.svg` | SFF sprites |
| `video.svg` | AIR animations |
| `audio.svg` | SND sounds |
| `palette.svg` | ACT palettes |
| `document.svg` | anything else |
| `folder-base.svg`, `folder-scripts.svg`, `folder-images.svg`, `folder-audio.svg` | character root and file groups |

To add one, copy it from the same release tag and list it here.
